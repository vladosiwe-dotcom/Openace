# Openace — пробуждение

Мод для Minecraft 1.21.1 (NeoForge 21.1.150+). При входе на сервер игрок «просыпается»: лежит на спине, открывает глаза, поднимает голову, садится и встаёт.

- **Сам игрок** видит сцену от первого лица: сначала закрытые глаза, потом веки открываются, видно небо, горизонт, и всё переходит в обычный вид.
- **Остальные игроки рядом** видят со стороны 3D-модель с его скином. Кто подошёл позже, видит сцену с текущей фазы.
- Сцена длится 8 секунд и одинаково синхронна на сервере и всех клиентах. Пока игрок лежит, у него Сопротивление V.

Мод самостоятельный: ни от Solo Status, ни от других модов он не зависит. **GeckoLib 4** (4.4–4.x) нужен для полной модели со скином игрока. Без GeckoLib сцена играет упрощённо на ванильной модели.

## Настройки

`serverconfig/openace-server.toml`:

```toml
[awakening]
  enabled = true    # сцена при входе на сервер
  everyJoin = true  # false — только при самом первом входе
```

Команда `/openace awaken <игроки>` (уровень прав 2) проигрывает сцену ещё раз.

## Устройство

Подробно: [docs/AWAKENING.md](docs/AWAKENING.md). Там модель, анимации, Blockbench, мультиплеер, проверка двумя клиентами и видео.

- `src/main/java/com/vladosiwe/openace/`: сцена на сервере, сеть, конфиг, команда.
- `.../client/`: отрисовка, камера от первого лица, веки на экране; `.../client/geo/`: часть на GeckoLib.
- `tools/blockbench/awakening.py`: одна таблица ключевых кадров. Из неё собираются и игровые файлы, и проекты Blockbench в `art/blockbench/`.
